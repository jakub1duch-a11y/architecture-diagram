# architecture-diagram
Architecture overview with Mermaid diagrams

## Dovednosti
- Vytváření architektonických diagramů
- Vizualizace komponent, služeb a jejich interakcí
- Diagramy toků dat, deploymentu a infrastruktury
- Dokumentace systémových vztahů a rozhodnutí
- Přehledné prezentace pro developerské a business týmy

## Skills
- Mermaid diagram authoring
- System architecture visualization
- Component and service interaction mapping
- Infrastructure and deployment diagramming
- Technical documentation and stakeholder communication
